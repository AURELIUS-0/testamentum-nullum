TESTAMENTUM NULLUM — стартовый сайт

Внутри: главная страница, FRATER_001, архив SANCTUARIUM, OCTAVA, оформление CSS и сюжетная проверка пароля CUSTOS.

ПУБЛИКАЦИЯ ЧЕРЕЗ GITHUB PAGES:
1. Создай аккаунт на https://github.com/
2. Нажми New repository.
3. Назови его testamentum-nullum и выбери Public.
4. Открой репозиторий -> Add file -> Upload files.
5. Распакуй ZIP на компьютере и перетащи ВСЕ файлы и папки изнутри в GitHub (не сам ZIP).
6. Нажми Commit changes.
7. Открой Settings -> Pages.
8. В Build and deployment выбери Deploy from a branch.
9. Branch: main, folder: /(root), затем Save.
10. После публикации адрес будет https://ТВОЙ-НИК.github.io/testamentum-nullum/

Важно: пароль CUSTOS реализован в JavaScript и не является настоящей защитой. Это только ARG-загадка. Не помещай на сайт личные данные или настоящие пароли.
